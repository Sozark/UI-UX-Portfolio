About

I'm a full-stack web developer and design engineer with a B.S. in Computer Science from LSU and a minor in Digital Media Arts & Engineering. I build web applications end-to-end, from database and API design through responsive front-end code and deployment, using React, Node.js, ASP.NET Core, and SQL Server.

My IT background shapes how I build. As an IT intern at Baton Rouge STEM, I led a website redesign that grew program registrations 250% (20 to 70+), built Python and C# automation tools, supported CI/CD deployment pipelines, and provided Windows systems support. I also built LSU Parking Tracker, a full-stack app with a Python, ASP.NET Core, and SQL Server backend and REST APIs that processed real-time parking data.

As an independent developer, I take client projects from requirements to launch, including StayFinder AI, NJEM, and Sidéral. My design training shows in the front end: I work in Figma and build to WCAG/ADA standards from the start. That includes accessibility-first games, BandBuilder and Tempo Trails, usability tested with children ages 5–8.

I'm looking for full-stack web developer, software engineer, and design engineer roles where I can build reliable products and work closely with the people who use them. I'm based in New Orleans and open to relocation.
